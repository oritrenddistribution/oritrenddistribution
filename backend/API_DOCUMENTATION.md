# Oritrend Dashboard Backend - API Routes Documentation\n\n## Overview\nComplete REST API for Oritrend music distribution platform with authentication, artist management, song uploads, and file management.\n\n## Base URL\n```\nhttp://localhost:5000/api\n```\n\n## Authentication\nAll protected routes require a Bearer token in the Authorization header:\n```\nAuthorization: Bearer <your_jwt_token>\n```\n\n---\n\n## 🔐 Authentication Routes\n\n### 1. Register User\n**POST** `/auth/register`\n\n**Request Body:**\n```json\n{\n  \"email\": \"artist@example.com\",\n  \"password\": \"securePassword123\",\n  \"firstName\": \"John\",\n  \"lastName\": \"Doe\"\n}\n```\n\n**Response (201):**\n```json\n{\n  \"success\": true,\n  \"message\": \"User registered successfully. Please check your email to verify your account.\",\n  \"token\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"user\": {\n    \"id\": \"507f1f77bcf86cd799439011\",\n    \"email\": \"artist@example.com\",\n    \"firstName\": \"John\",\n    \"lastName\": \"Doe\",\n    \"verified\": false\n  }\n}\n```\n\n---\n\n### 2. Login User\n**POST** `/auth/login`\n\n**Request Body:**\n```json\n{\n  \"email\": \"artist@example.com\",\n  \"password\": \"securePassword123\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Login successful\",\n  \"token\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"user\": {\n    \"id\": \"507f1f77bcf86cd799439011\",\n    \"email\": \"artist@example.com\",\n    \"firstName\": \"John\",\n    \"lastName\": \"Doe\",\n    \"verified\": true,\n    \"role\": \"artist\"\n  }\n}\n```\n\n---\n\n### 3. Verify Email\n**POST** `/auth/verify-email`\n\n**Request Body:**\n```json\n{\n  \"token\": \"verification_token_from_email\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Email verified successfully\",\n  \"user\": {\n    \"id\": \"507f1f77bcf86cd799439011\",\n    \"email\": \"artist@example.com\",\n    \"verified\": true\n  }\n}\n```\n\n---\n\n### 4. Forgot Password\n**POST** `/auth/forgot-password`\n\n**Request Body:**\n```json\n{\n  \"email\": \"artist@example.com\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Password reset link sent to your email\"\n}\n```\n\n---\n\n### 5. Reset Password\n**POST** `/auth/reset-password`\n\n**Request Body:**\n```json\n{\n  \"token\": \"reset_token_from_email\",\n  \"password\": \"newPassword123\",\n  \"confirmPassword\": \"newPassword123\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Password reset successfully. You can now login with your new password.\"\n}\n```\n\n---\n\n### 6. Refresh Token\n**POST** `/auth/refresh-token` ⭐ Protected\n\n**Request Body:**\n```json\n{\n  \"token\": \"expired_or_valid_token\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Token refreshed successfully\",\n  \"token\": \"new_jwt_token\"\n}\n```\n\n---\n\n### 7. Get Current User\n**GET** `/auth/me` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"user\": {\n    \"id\": \"507f1f77bcf86cd799439011\",\n    \"email\": \"artist@example.com\",\n    \"firstName\": \"John\",\n    \"lastName\": \"Doe\",\n    \"verified\": true,\n    \"role\": \"artist\",\n    \"lastLogin\": \"2024-05-24T10:00:00.000Z\"\n  },\n  \"artist\": {\n    \"_id\": \"607f1f77bcf86cd799439011\",\n    \"artistName\": \"John Artist\",\n    \"genres\": [\"Hip-Hop\", \"Rap\"],\n    \"verified\": true\n  }\n}\n```\n\n---\n\n## 👤 Artist Routes\n\n### 1. Get Artist Profile\n**GET** `/artists/profile` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"artist\": {\n    \"_id\": \"607f1f77bcf86cd799439011\",\n    \"userId\": \"507f1f77bcf86cd799439011\",\n    \"artistName\": \"John Artist\",\n    \"bio\": \"Independent hip-hop artist from Lagos\",\n    \"profileImage\": \"https://s3.amazonaws.com/...\",\n    \"genres\": [\"Hip-Hop\", \"Rap\"],\n    \"socialLinks\": {\n      \"spotify\": \"https://spotify.com/...\",\n      \"instagram\": \"https://instagram.com/...\"\n    },\n    \"stats\": {\n      \"totalSongs\": 15,\n      \"totalStreams\": 50000,\n      \"totalEarnings\": 2500\n    },\n    \"verified\": true,\n    \"createdAt\": \"2024-05-20T10:00:00.000Z\"\n  }\n}\n```\n\n---\n\n### 2. Create Artist Profile\n**POST** `/artists/profile` ⭐ Protected\n\n**Request Body:**\n```json\n{\n  \"artistName\": \"John Artist\",\n  \"bio\": \"Independent hip-hop artist from Lagos\",\n  \"genres\": [\"Hip-Hop\", \"Rap\"],\n  \"socialLinks\": {\n    \"spotify\": \"https://spotify.com/...\",\n    \"instagram\": \"https://instagram.com/...\",\n    \"twitter\": \"https://twitter.com/...\"\n  }\n}\n```\n\n**Response (201):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Artist profile created successfully\",\n  \"artist\": { ... }\n}\n```\n\n---\n\n### 3. Update Artist Profile\n**PUT** `/artists/profile` ⭐ Protected\n\n**Request Body:** (all fields optional)\n```json\n{\n  \"artistName\": \"Updated Artist Name\",\n  \"bio\": \"Updated bio\",\n  \"genres\": [\"Afrobeats\"],\n  \"profileImage\": \"new_image_url\"\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Artist profile updated successfully\",\n  \"artist\": { ... }\n}\n```\n\n---\n\n### 4. Get Dashboard\n**GET** `/artists/dashboard` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"dashboard\": {\n    \"artist\": {\n      \"id\": \"607f1f77bcf86cd799439011\",\n      \"artistName\": \"John Artist\",\n      \"profileImage\": \"url\",\n      \"genres\": [\"Hip-Hop\"]\n    },\n    \"subscription\": {\n      \"plan\": \"pro\",\n      \"status\": \"active\",\n      \"endDate\": \"2025-05-24\",\n      \"uploads\": { \"used\": 20, \"limit\": null }\n    },\n    \"stats\": {\n      \"totalSongs\": 15,\n      \"liveSongs\": 12,\n      \"totalStreams\": 50000,\n      \"totalEarnings\": 2500\n    },\n    \"recentSongs\": [\n      {\n        \"_id\": \"707f1f77bcf86cd799439011\",\n        \"title\": \"My Latest Track\",\n        \"status\": \"live\",\n        \"createdAt\": \"2024-05-24T10:00:00.000Z\"\n      }\n    ]\n  }\n}\n```\n\n---\n\n### 5. Get Artist Statistics\n**GET** `/artists/stats` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"stats\": {\n    \"totalSongs\": 15,\n    \"liveSongs\": 12,\n    \"draftSongs\": 3,\n    \"totalStreams\": 50000,\n    \"totalDownloads\": 5000,\n    \"totalEarnings\": 2500,\n    \"platformStats\": {\n      \"spotify\": { \"streams\": 30000, \"downloads\": 3000, \"earnings\": 1500 },\n      \"apple\": { \"streams\": 15000, \"downloads\": 1500, \"earnings\": 750 },\n      \"youtube\": { \"streams\": 5000, \"downloads\": 500, \"earnings\": 250 }\n    }\n  }\n}\n```\n\n---\n\n## 🎵 Song Routes\n\n### 1. Get All Songs\n**GET** `/songs` ⭐ Protected\n\n**Query Parameters:**\n- `status`: draft, pending_approval, approved, scheduled, live, removed, failed\n- `platform`: spotify, apple, youtube, etc.\n- `page`: default 1\n- `limit`: default 10\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"songs\": [\n    {\n      \"_id\": \"707f1f77bcf86cd799439011\",\n      \"title\": \"My Song\",\n      \"genre\": \"Hip-Hop\",\n      \"status\": \"live\",\n      \"platforms\": [\"spotify\", \"apple\"],\n      \"createdAt\": \"2024-05-24T10:00:00.000Z\"\n    }\n  ],\n  \"pagination\": {\n    \"total\": 15,\n    \"pages\": 2,\n    \"currentPage\": 1,\n    \"limit\": 10\n  }\n}\n```\n\n---\n\n### 2. Create Song\n**POST** `/songs` ⭐ Protected\n\n**Request Body:**\n```json\n{\n  \"title\": \"My New Song\",\n  \"artists\": [\"John Artist\"],\n  \"featuredArtists\": [\"Guest Artist\"],\n  \"genre\": \"Hip-Hop\",\n  \"releaseDate\": \"2024-06-15\",\n  \"duration\": 240,\n  \"description\": \"Song description\",\n  \"platforms\": [\"spotify\", \"apple\", \"youtube\"]\n}\n```\n\n**Response (201):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Song created successfully. Upload audio file next.\",\n  \"song\": {\n    \"_id\": \"707f1f77bcf86cd799439011\",\n    \"title\": \"My New Song\",\n    \"status\": \"draft\",\n    \"createdAt\": \"2024-05-24T10:00:00.000Z\"\n  }\n}\n```\n\n---\n\n### 3. Get Song Details\n**GET** `/songs/:id` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"song\": {\n    \"_id\": \"707f1f77bcf86cd799439011\",\n    \"title\": \"My Song\",\n    \"artists\": [\"John Artist\"],\n    \"genre\": \"Hip-Hop\",\n    \"releaseDate\": \"2024-06-15\",\n    \"duration\": 240,\n    \"status\": \"live\",\n    \"platforms\": [\"spotify\", \"apple\"],\n    \"audioFile\": {\n      \"s3Url\": \"https://s3.amazonaws.com/.../audio.mp3\",\n      \"fileSize\": 5000000\n    },\n    \"coverArt\": {\n      \"s3Url\": \"https://s3.amazonaws.com/.../cover.jpg\"\n    },\n    \"analytics\": {\n      \"totalStreams\": 5000,\n      \"totalEarnings\": 250\n    }\n  }\n}\n```\n\n---\n\n### 4. Update Song\n**PUT** `/songs/:id` ⭐ Protected\n\n**Request Body:** (all fields optional)\n```json\n{\n  \"title\": \"Updated Title\",\n  \"genre\": \"Afrobeats\",\n  \"releaseDate\": \"2024-07-01\",\n  \"duration\": 240,\n  \"platforms\": [\"spotify\", \"apple\", \"youtube\"]\n}\n```\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Song updated successfully\",\n  \"song\": { ... }\n}\n```\n\n---\n\n### 5. Delete Song\n**DELETE** `/songs/:id` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"message\": \"Song deleted successfully\"\n}\n```\n\n---\n\n### 6. Get Song Analytics\n**GET** `/songs/:id/analytics` ⭐ Protected\n\n**Response (200):**\n```json\n{\n  \"success\": true,\n  \"analytics\": {\n    \"songTitle\": \"My Song\",\n    \"status\": \"live\",\n    \"distributedAt\": \"2024-05-24T10:00:00.000Z\",\n    \"totalStreams\": 5000,\n    \"totalDownloads\": 500,\n    \"totalEarnings\": 250,\n    \"platformStats\": [\n      { \"platform\": \"spotify\", \"streams\": 3000, \"downloads\": 300, \"earnings\": 150 },\n      { \"platform\": \"apple\", \"streams\": 2000, \"downloads\": 200, \"earnings\": 100 }\n    ]\n  }\n}\n```\n\n---\n\n### 7.
